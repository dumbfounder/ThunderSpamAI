ThunderSpam AI

Model Provider

Choose where ThunderSpam AI sends classification requests.

ThunderSpam AI sends only the metadata and text of each email to this Ollama instance. Use localhost when possible to keep messages on-device.

Set an OpenAI-compatible API base URL. For local servers (LM Studio, llama.cpp, text-generation-webui), use the URL they provide (for example, http://127.0.0.1:1234/v1).

Create or manage a key at platform.openai.com/api-keys. Charges apply to API usage—review your account limits before enabling.

Enter a chat completion model ID supported by your endpoint (for example, gpt-5.2 or a local model name). If you use a different model, it'll be added to this list after you save it.

              classification without changing the required JSON format.
            

            

            

              
              
            

            

              
              
              

                This guidance is appended to the prompt to decide needs_attention and

              In your guidance you can reference placeholders such as {{from}}, {{to}},
              {{subject}}, {{date}}, {{email_text}}, or

Ollama Quick Start

            
    
              
  1. Install Ollama from ollama.ai, then launch it.
    2. 
              
  2. Download a model tuned for text classification, for example:
    3. 
            

            
ollama pull llama3:8b
ollama pull mistral
ollama pull phi3:mini

            

              Apple Silicon or modern NVIDIA GPUs can handle llama3:8b. For CPU-only systems, start with
              phi3:mini or mistral.
            

            

              To expose Ollama remotely (not recommended), set OLLAMA_HOST=0.0.0.0 and secure the network.
              See the Ollama usage
              guide for details.
